Missing `role="group"` on filter containers and `aria-pressed` on stateful toggle buttons makes keyboard and screen reader navigation unclear.\n**Action:** Always ensure that custom button groups acting as tabs or filters have an appropriate `role="group"` on their container, and use `aria-pressed` on the buttons themselves to indicate the active state. Add `aria-label` to search inputs lacking visible labels.

## 2026-07-29 - Focus Restoration on Modal Close
**Learning:** When managing focus transitions in Preact after state changes (like closing a modal), simply restoring focus using a `useEffect` directly can accidentally steal focus on the initial component mount. It is critical to track the previous state (e.g., using a `wasOpen` ref). Furthermore, wrapping `ref.current?.focus()` in a `setTimeout(..., 0)` is necessary to ensure the DOM has updated asynchronously before the focus is applied.
**Action:** When restoring focus on modal close, use a `useRef` flag to track the previous open state and a `setTimeout(..., 0)` to apply focus safely after DOM updates.
