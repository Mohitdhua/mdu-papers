Missing `role="group"` on filter containers and `aria-pressed` on stateful toggle buttons makes keyboard and screen reader navigation unclear.\n**Action:** Always ensure that custom button groups acting as tabs or filters have an appropriate `role="group"` on their container, and use `aria-pressed` on the buttons themselves to indicate the active state. Add `aria-label` to search inputs lacking visible labels.

## 2026-06-30 - Prevent focus stealing on Preact component mount
**Learning:** When using a `useEffect` dependency array (e.g., `[open]`) to manage focus transitions in a modal component (like shifting focus on open/close), a naïve implementation will cause the closed state logic to run on initial mount. This can accidentally steal focus and snap the user's viewport to the component unexpectedly. Furthermore, Preact DOM updates can happen asynchronously, so focus changes should be scheduled.
**Action:** Always use a `useRef` flag (e.g., `wasOpen`) to track the previous open state and verify the modal was actually previously open before restoring focus on close. Always wrap `.focus()` calls in `setTimeout(..., 0)` to ensure the DOM has fully updated before focusing.
